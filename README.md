# Modified-Integrated-Smart-Traffic-Management-System-

This sketch runs an IR-triggered enforcement routine combined with an MFRC522 RFID reader to distinguish emergency (ambulance) from ordinary vehicles. The program cycles traffic states internally (GREEN → YELLOW → RED) and continuously monitors an IR sensor: when the IR goes low (object detected) and the intersection is in RED or YELLOW, it attempts to read an RFID tag for a short timeout. If the UID matches the ambulance UID, the code enters an ambulance override state — granting an immediate green (AMBULANCE_OVERRIDE) for a bounded time. If the UID matches a “normal” vehicle or no tag is presented, the system starts an alarm routine: a flashing red LED and a buzzer/tone sequence for a fixed alarm duration. The RFID read function polls the RC522 module for a limited window to avoid blocking. Lighting is centrally managed: updateLights() writes the LED outputs according to the current enum state, and changeState() updates timing and prints status for debugging. The alarm handler multiplexes LED flashing and buzzer control while also stopping after the alarm duration. IR input is debounced and edge-detected so detection is robust. Overall, this code integrates detection, identity-based prioritization, and audible enforcement in a nonblocking, time-driven loop suitable for prototype intersection control.
